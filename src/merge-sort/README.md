# Merge Sort (병합 정렬)

## 1. 소개

병합 정렬은 O(NlogN)의 시간 복잡도를 가지며, 어떤 경우에도 성능이 보장되어 안정적이라는 장점이 있습니다. 이 때문에 대용량 데이터를 정렬하거나 안정성이 중요한 상황에서 사용됩니다.

## 2. 원리

병합 정렬은 다음과 같은 세 단계의 분할 정복 전략을 따릅니다.

### 1. 분할

정렬할 배열을 더 이상 나눌 수 없을 때까지(원소가 하나만 남을 때까지) 재귀적으로 두 개의 부분 배열로 나눕니다.

### 2. 정복

각 부분 배열을 정렬합니다. 부분 배열의 크기가 1이라면 이미 정렬된 것으로 간주합니다.

### 3. 결합

정렬된 두 개의 부분 배열을 하나의 정렬된 배열로 병합합니다. 이 과정에서 추가적인 임시 배열이 필요합니다.

## 3. 시간 복잡도 (Time Complexity)

### 최선, 평균, 최악 모두 O(NlogN)

배열을 반으로 나누는 과정이 `logN`번 일어나고, 각 단계에서 병합하는 과정이 `N`번의 연산을 필요로 하므로 시간 복잡도는 항상 `O(NlogN)`이 됩니다.

## 4. 공간 복잡도 (Space Complexity)

### O(N)

두 부분 배열을 병합할 때, 정렬된 결과를 담을 임시 배열이 필요합니다. 이 임시 배열의 크기는 원래 배열의 크기(`N`)와 같으므로 `O(N)`의 추가 공간이 필요합니다.

## 5. 구현 기능

JavaScript의 `Array.prototype.sort()`와 유사하게, 원본 배열을 직접 수정하는(mutable) 방식으로 `mergeSort` 함수를 구현합니다.

### 인자

`compareFunction`: 정렬 기준을 정의하는 비교 함수. (예: `(a, b) => a - b`는 오름차순 정렬)

함수가 제공되지 않으면, 배열의 요소들은 문자열로 변환되어 각 문자의 유니코드 코드 포인트 값에 따라 정렬됩니다.

## 6. 사용 예시

```typescript
import {mergeSort} from './mergeSort';

const numbers = [5, 2, 8, 1, 9, 4];
mergeSort(numbers, (a, b) => a - b);
console.log(numbers); // 출력: [1, 2, 4, 5, 8, 9]

const fruits = ['banana', 'apple', 'cherry'];
mergeSort(fruits);
console.log(fruits); // 출력: ['apple', 'banana', 'cherry']
```

## 7. 구현

### `mergeSort(array, comparator)`

병합 정렬을 실행하는 메인 함수입니다.

- 내부적으로 `mergeSortRecursive`를 호출하여 정렬된 새로운 배열을 생성한 후, 원본 배열의 내용을 이 정렬된 배열의 내용으로 교체합니다.
- `comparator` 함수를 인자로 받으며, 제공되지 않을 경우 `defaultComparator`를 사용하여 문자열 기준으로 정렬합니다.

### `mergeSortRecursive(arr, comparator)`

재귀적으로 배열을 분할하고 정복하는 역할을 담당하는 핵심 함수입니다.

- 배열의 길이가 1 이하가 될 때까지 재귀적으로 배열을 반으로 나눕니다
- 나누어진 배열들을 각각 재귀 호출을 통해 정렬합니다
- 정렬된 두 개의 부분 배열을 `merge` 함수를 통해 병합합니다

### `merge(left, right, comparator)`

정렬된 두 개의 부분 배열(`left`, `right`)을 하나로 병합하는 함수입니다.

- 두 배열의 첫 번째 원소부터 비교하며, `comparator`의 결과에 따라 더 작은(또는 우선순위가 높은) 원소를 새로운 결과 배열에 순서대로 추가합니다.
- 한쪽 배열의 모든 원소가 소진되면, 남은 다른 쪽 배열의 원소들을 결과 배열에 모두 추가합니다.
- 병합된 정렬된 배열을 반환합니다.
